# Patinhas & Estilo · site

Site de uma página da Patinhas & Estilo | Banho e Tosa (Feitosa, Maceió).
Feito pela Frattini Labs. HTML, CSS e JS puros, sem dependências: basta abrir o `index.html`.

Versão de demonstração: a tag `<meta name="robots" content="noindex">` no `index.html`
impede a indexação e deve ser removida quando o site for ao ar oficialmente.
